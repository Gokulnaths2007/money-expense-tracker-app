
# Expense Tracker Web App

## About
The Expense Tracker is a simple web application built using HTML, CSS, and JavaScript. It helps users manage their income and expenses and calculate their current balance.

## Features
- Add income transactions
- Add expense transactions
- Select transaction categories
- Automatically calculate total income, expenses, and balance
- View transaction history
- Delete transactions
- Save transactions using browser localStorage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add income and expense transactions.
